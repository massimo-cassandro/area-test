# Unsplash Random Photo

* March 2023
* v.2 May 2026

Random photo using the [Unsplash Api](https://unsplash.com/developers).
Requires [BlurHash](https://blurha.sh/).

[demo](https://massimo-cassandro.github.io/area-test/2023-03-unsplash-random-photo/index.html).

> Please note that the Unsplash API key used in this demo was created for development use only and has hourly and daily limitations. 

Icons from [Phosphor Icons](https://phosphoricons.com/).

See also <https://github.com/massimo-cassandro/unsplash-page>.
